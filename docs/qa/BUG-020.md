## Diagnosis (for the fixer)

The BUG-017 rewrite was written against the boss contract as of its own
commit; `app/models.py` boss validation is stricter than the tests'
assumptions (no `size=None` default; cell-type ' ' rejected). 11/11 of
the file failing — including basic fixture construction — indicates a
systemic fixture/helper mismatch, not 11 independent bugs: the shared
test fixture/helpers in `test_boss.py` need to be aligned with the current
`app/models.py` boss contract (valid cell types, explicit valid `size`).
Test-side fix; do not loosen `app/models.py` validation.
