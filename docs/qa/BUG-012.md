# BUG-012 — (withdrawn during review)

*This file was drafted during independent QA review of the Pan & Zoom feature
(feat/pan-zoom) and withdrawn before logging: on re-analysis the suspected
AC20 test defect does not hold. `test_ac20_rapid_key_repeat`'s `q === 1`
assertion (queue length after 5 unflushed keydowns) **does** detect a
regression that removes the `scheduleRender` coalescing guard (queue would
read 5), and the implementation satisfies AC20's "at most one rAF render per
frame" (harness `dispatch()` = one frame; exactly one callback flushes).
AC20 therefore passes. No bug.*

*If a future numbering gap is expected, this number is consumed by the
withdrawn draft above; the next live bug is BUG-013.*
